Besoin d'aide pour vous connecter?

  • Microsoft 365 et Campus LAPIQ : un seul compte, votre adresse @lapiq.org et son mot de passe Microsoft. Sur la page de connexion du Campus, choisissez le bouton « Microsoft ».
  • Une fois connecté à Microsoft 365, le Campus vous reconnaît généralement sans redemander le mot de passe.
  • Yapla (carte de membre, adhésion) : utilisez le courriel associé à votre adhésion. Le lien « Mot de passe oublié » vous permet de le réinitialiser.

Les liens s'ouvrent dans un nouvel onglet. Aucun mot de passe n'est conservé par ce portail.
